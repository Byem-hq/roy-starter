# 더 넓은 자동화 — 완성형 ROY는 어떻게 일하나

이 킷의 스킬 두 개는 ROY가 하는 일의 **아주 작은 조각**이에요. 여기서는 전체 모양과, 다음에 만들어 볼 만한 스킬 세 개의 **설계 예시**를 보여 드려요.
⛔ 이 문서의 스킬들은 실행 코드가 들어 있지 않아요. 설계 예시를 보고 [`build-your-own/`](../build-your-own/workflow-template.md) 으로 직접 만들어 보세요.

## 1. 전체 흐름

```
   [회사 이해]            [진단]                       [기획]              [실행 · 확인]
 브랜드 조사  ──▶  광고 성과 점검 ─┬─▶ 광고 세팅 점검  ──▶  다음 액션 정리  ──▶  사람이 승인
                   랜딩 진단     ─┘   소재 분석                              ──▶  결과 다시 점검
        ▲                                                                       │
        └─────────────────────── 사람이 내린 결정 · 기준이 다음 판단에 쓰임 ◀──────┘
```

- **스킬 하나 = 업무 하나.** 각자 입력 · 처리 순서 · 판단 기준 · 결과물이 정해져 있어요.
- 완성형 ROY는 상황을 보고 **어떤 스킬을 쓸지 고르고 이어 붙여요.** 그리고 사람이 승인한 것만 실행해요.
- 이 킷에 있는 것은 가운데 두 칸(광고 성과 점검 · 랜딩 진단)의 맛보기 버전이에요.

| | 이 킷 | 완성형 ROY |
|---|---|---|
| 스킬 | 2개 · 하나씩 직접 부름 | 여러 개 · 상황에 맞게 골라서 이음 |
| 데이터 | CSV 파일 · 공개 화면 | 광고 · 주문 · 사이트 데이터 연결 |
| 판단 기준 | 일반적인 기준 몇 개 | 회사마다 쌓인 기준 · 검증된 판단 원칙 |
| 실행 | 보고서까지 | 사람 승인 → 실행 → 결과 확인 |

---

## 2. 설계 예시 ① 브랜드 조사

새 브랜드를 맡았을 때 「이 회사는 무엇을 누구에게 어떻게 파나」를 정리하는 스킬.

| 칸 | 설계 |
|---|---|
| 이름 · 언제 | 브랜드 조사 — 새 브랜드를 처음 맡았을 때 |
| 입력 데이터 | 사이트 · 인스타 링크 · 브랜드 이름 (Meta 광고 라이브러리 검색용) |
| 처리 순서 | ① 사이트에서 상품 · 가격 구성 · 판매처 ② 인스타에서 말투 · 자주 쓰는 메시지 ③ 광고 라이브러리에서 지금 돌고 있는 광고 · 문구 ④ 정리 |
| 판단 기준 | 화면에서 확인한 것만 「확인」, 추정은 「추정」으로 구분 · 가격 · 재고는 확실할 때만 |
| 결과물 형식 | 무엇을 · 얼마에 · 누구에게 · 어디서 · 어떤 메시지로 · 모름 목록 |
| 사람이 정하는 것 | 무엇을 성과로 볼지 · 무엇이 먼저인지(방문자 · 매출 · 이익) |

## 3. 설계 예시 ② 광고 세팅 점검

성과가 갑자기 달라졌을 때 「누가 무엇을 바꿨나」부터 확인하는 스킬.

| 칸 | 설계 |
|---|---|
| 이름 · 언제 | 광고 세팅 점검 — 성과가 갑자기 달라졌을 때 · 새 캠페인 시작 전 |
| 입력 데이터 | 광고관리자 활동 기록(변경 내역) · 캠페인 · 광고 세트 설정 내보내기 (예산 · 상태 · 타겟 · 입찰) |
| 처리 순서 | ① 성과가 달라진 날짜 찾기 ② 그 무렵 변경 내역 맞춰 보기 ③ 꺼짐 · 제한 · 예산 변화 확인 ④ 점검표 |
| 판단 기준 | 사람이 일부러 끈 광고는 다시 켜자고 하지 않고 이유를 묻는다 · 한 광고 지출이 늘었다고 예산을 올렸다고 보지 않는다 (지출은 배분 결과) |
| 결과물 형식 | 날짜별 변경 표 · 성과 변화와 겹치는 변경 · 확인할 질문 |
| 사람이 정하는 것 | 다시 켤지 · 예산을 바꿀지 |

## 4. 설계 예시 ③ 소재 분석

「어떤 소재가 왜 잘됐나」를 찾아 다음 소재로 잇는 스킬.

| 칸 | 설계 |
|---|---|
| 이름 · 언제 | 소재 분석 — 다음 소재를 만들기 전 |
| 입력 데이터 | 광고별 성과(광고 성과 점검 결과) · 소재 이미지 · 영상 캡처 · 카피 (광고 이름과 같은 파일명) |
| 처리 순서 | ① 성과 상위 · 하위 소재 고르기 (표본 충분한 것만) ② 소재마다 첫 장면 · 메시지 · 형식 기록 ③ 상위에만 있는 공통점 찾기 ④ 다음 소재 작업지시서 |
| 판단 기준 | 표본이 작은 소재는 「아직 모름」 · 공통점은 두 개 이상 소재에서 보일 때만 |
| 결과물 형식 | 잘된 소재 · 안된 소재 표 · 공통점 · 다음 소재 작업지시서 (메시지 · 첫 장면 · 형식 · 하지 말 것) |
| 사람이 정하는 것 | 브랜드에서 쓰면 안 되는 표현 · 할인 표현 허용 여부 |

## 5. 스킬을 이으면

```
광고 성과 점검  →  「D 광고: 클릭률은 높은데 구매율이 낮다」
       ↓
랜딩 진단       →  「D 광고가 도착하는 페이지 첫 화면에 가격이 안 보인다」
       ↓
소재 분석       →  「D 광고 첫 장면은 살리고, 끝을 세트 구성으로」
       ↓
사람            →  승인 · 보류 · 반대 + 이유  →  다음 판단의 기준이 된다
```

이 연결을 사람이 매번 하는 게 아니라 **ROY가 골라서 이어 주고, 사람은 결정만** 하는 것 — 그게 완성형 ROY예요.
