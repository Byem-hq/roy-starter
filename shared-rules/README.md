# 기준 · 스킬 공유하기 (원하는 사람만)

내가 바꾼 판단 기준이나 내가 만든 스킬이 다른 마케터에게도 쓸모 있을 것 같으면 여기로 보내 주세요.
⛔ 의무가 아니에요. 보내고 싶은 것만.

## 무엇을 보내나
`shared-rules/<내 이름>.md` 파일 하나 — 아래 형식.

```markdown
# <내 이름>의 기준
업종: <한 단어 — 예: 건강식품 · 의류 · 교육 · B2B>

## 바꾼 기준 · 만든 스킬
- <무엇을 · 왜 — 예: 비교 기간을 14일로 — 우리는 주말 주문이 몰려서 7일은 흔들림>
- <스킬이면: 이름 · 한 줄 설명 · 처리 순서 요약>
```

## 보내기 전에 꼭
- ⛔ 회사 이름 · 브랜드 · 상품명 · 실제 매출 · 광고비 숫자를 지워 주세요. 「14일」 「구매 5건」처럼 **기준이 되는 숫자**는 남겨도 돼요.
- ⛔ `workspace/` 의 데이터 · 보고서는 넣지 마세요.
- ROY에게 「공유본 만들어줘」라고 하면 회사 정보를 가린 초안을 만들어 줘요. **직접 읽고** 확인한 뒤 보내세요.

## 보내는 방법
```
git checkout -b rules/<이름>
git add shared-rules/<이름>.md
git commit -m "rules: <이름> 규칙 공유"
git push -u origin rules/<이름>
```
내 Fork 화면에 뜨는 「Compare & pull request」 → 받는 곳이 `Byem-hq/roy-starter` 인지 확인하고 보내기.
