# ROY Starter Kit

> 🖼 처음이면 [소개 페이지](docs/intro.html)를 먼저 보세요 — 파일을 더블클릭하면 브라우저로 열려요.

**퍼포먼스 마케터를 위한 AI 업무 자동화 입문**

AI에게 매번 질문하는 대신, **업무 자체를 스킬로** 만들어 보는 Claude Code 폴더예요.
작은 ROY 하나를 직접 돌려 보고 → 어떻게 만들어졌는지 펼쳐 보고 → 내 업무 스킬을 만들기 시작해요.

## 받는 방법
1. GitHub에서 이 저장소 오른쪽 위 **Fork** → 내 계정으로 복사
2. 내 Fork를 내려받아 Claude Code로 열기
```
git clone https://github.com/<내 계정>/roy-starter.git
cd roy-starter
claude
```
새 버전은 내 Fork 화면의 **Sync fork** 버튼 → `git pull`. `workspace/`는 그대로 남아요.

## 먼저 준비 — 설치 2개 · 확인 1개

| 설치 | 왜 필요한가 |
|---|---|
| [Claude Code](https://claude.com/claude-code) | ROY가 일하는 곳이에요 |
| **Chrome + Claude 확장** ([Chrome 웹스토어](https://chromewebstore.google.com)에서 「Claude」 검색) | ROY가 **랜딩페이지와 광고관리자 화면을 직접 봐야** 비즈니스 모델 판단과 랜딩 진단이 돼요. 없으면 광고 파일 분석만 돼요 |
| `python3` (확인만) | 광고 숫자 계산용 — **맥에는 보통 이미 설치돼 있어요.** 터미널에서 `python3 --version` 이 나오면 끝. 안 나오면 ROY에게 물어보세요 |

## ROY에게 주는 것 — 3가지

| # | 주는 것 | 어떻게 |
|---|---|---|
| 1 | **Meta 광고 파일** | 광고관리자 → 광고 탭 → 기간 **최근 14일** → 분석 기준 **일** → 내보내기(CSV · xlsx) → `workspace/data/` 에 넣기 |
| 2 | **랜딩페이지 링크** | 광고를 누르면 도착하는 페이지 주소 |
| 3 | **광고관리자 링크** | 캠페인 화면 주소 — ROY는 **보기만** 하고 아무것도 누르지 않아요 |

## 받는 것 — 보고서 1부 (`workspace/reports/`)

| 칸 | 내용 |
|---|---|
| 광고 성과 | **최근 7일 vs 그 전 7일** — 지출 · 클릭률 · 구매 · CPA · ROAS, 캠페인별 · 광고별 · 일별 표 |
| ROY 판단 | 무엇이 왜 달라졌는지 — 판단마다 근거 숫자와 규칙 번호([rs-1~6](rules.md)) |
| 할 일 | **승인 · 보류 · 반대**로 답하는 제안 목록 |
| 랜딩 진단 | 체크리스트 9개(첫 화면 · CTA · 신뢰 요소) + **먼저 고칠 것 3개** |
| 계정 상태 | 켜짐 · 꺼짐 · 예산 · 최근 변경 (광고관리자 화면 기준) |

## 시작하기
Claude Code에서 이 폴더를 열고 이렇게 말하세요.
(처음 「이 폴더를 믿을까요?」 → **예** · 내 스킬을 만들 때 `.claude/skills/` 쓰기를 물으면 그것도 **예**)

```
ROY 시작하기
```

ROY가 위 3가지를 받으면, 분석 전에 **먼저 물어요**:
1. **비즈니스 모델** — 랜딩을 보고 「상품을 바로 사는 쇼핑몰이네요, 맞나요?」처럼 판단하고 확인받아요
2. **목표** — 쇼핑몰이면 목표 ROAS · 평균 주문금액, 문의형이면 문의 1건당 비용. 답은 `workspace/goal.md` 에 저장돼 다음 보고서부터 기준이 돼요. 아직 없으면 「없음」이라고 하면 돼요

그다음 보고서를 만들어요.

## 무엇이 다른가요

| | 그냥 물어보기 | ROY 미니 스킬 |
|---|---|---|
| 말 | 「이 광고 데이터 분석해 줘」 | 「광고 분석해 줘」 |
| 일어나는 일 | AI가 그때그때 지표를 고르고 자유롭게 설명 | 데이터 검증 → 지표 계산 → 변화 비교 → 확인해 볼 것 → 보고서 저장 |
| 결과 | 매번 기준 · 형식이 달라질 수 있어요 | 같은 파일이면 같은 숫자 · 같은 형식 |

광고 숫자는 AI가 아니라 [`tools/ads_check.py`](tools/ads_check.py)가 늘 같은 방법으로 계산해요. AI는 그 결과를 읽고 정해진 형식으로 보고서를 써요.

## 내 데이터는 어디에?
전부 `workspace/` 한 곳에 생겨요. 이 폴더는 **GitHub에 올라가지 않게** 막혀 있어요.

```
workspace/
├ data/       내가 넣은 광고 CSV · 캡처
└ reports/    ROY가 쓴 보고서
```

## 꼭 지킬 것
- ⛔ 광고 계정 토큰 · 비밀번호 · 고객사 정보는 이 폴더에 올리지 마세요. 채팅에도 붙여 넣지 마세요.
- ⛔ ROY는 광고를 켜고 끄거나 예산을 바꾸지 않아요. 보기만 해요.
- 랜딩 진단은 **공개된 화면에서 보이는 것만** 점검해요. 방문자 데이터를 본 게 아니에요.
- 이 킷은 맛보기예요. 여러 업무를 스스로 골라 잇는 판단 · 자동 실행 · 광고 API 연결은 들어 있지 않아요 → [완성형 ROY](docs/roy-workflow.md)
