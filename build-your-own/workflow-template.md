# 내 업무 쪼개기

스킬은 「AI에게 하는 부탁」이 아니라 **내 업무의 절차서**예요.
매주 반복하는 일 하나를 골라 아래 다섯 칸을 채워 보세요. ROY에게 「이거 같이 채워줘」라고 해도 돼요.

> 💡 고르기 좋은 업무: 매주 · 매일 반복하고, 입력이 비슷하고, 결과물 모양이 정해져 있는 일.
> 예) 주간 광고 리포트 · 경쟁사 광고 모니터링 · 리뷰 모아서 불만 정리 · 소재 아이디어 10개 뽑기

---

## 예시 — 이 킷의 「광고 성과 점검」을 같은 칸에 채우면

| 칸 | 광고 성과 점검 |
|---|---|
| **이름 · 언제** | 광고 성과 점검 — 매주 월요일, 지난주가 어땠는지 볼 때 |
| **입력 데이터** | Meta 광고관리자 CSV (일별 · 광고 단위 · 최근 14일) |
| **처리 순서** | ① 칸 검증 ② 지표 계산 ③ 지난주와 비교 ④ 이상 신호 찾기 ⑤ 보고서 저장 |
| **판단 기준** | 같은 길이 기간끼리만 비교 · 구매 5건 미만이면 판단 보류 · 광고비가 10% 넘게 늘었는데 구매가 줄면 신호 · 원인은 단정하지 않음 |
| **결과물 형식** | 한 줄 → 숫자 표 → 가장 크게 달라진 곳 3개 → 확인해 볼 것 → 못 본 것 |
| **사람이 정하는 것** | 목표 ROAS · 무엇을 성과로 볼지 (AI가 정하지 않음) |

---

## 내 업무

| 칸 | 내 업무 |
|---|---|
| **이름 · 언제** | |
| **입력 데이터** | 무엇을 받나요? 어디서 · 어떤 형식으로? |
| **처리 순서** | 내가 실제로 하는 순서대로 3~6단계 |
| **판단 기준** | 내가 「이상하다 · 괜찮다」를 무엇으로 판단하나요? 숫자로 쓸 수 있으면 숫자로 |
| **결과물 형식** | 누가 읽나요? 어떤 순서로 쓰면 바로 이해하나요? |
| **사람이 정하는 것** | AI에게 맡기면 안 되는 결정은? |

## 체크
- [ ] 처리 순서를 남이 읽고 그대로 따라 할 수 있나요?
- [ ] 판단 기준에 「적당히」 「잘」 같은 말 대신 기준이 있나요?
- [ ] 결과물 형식을 정했나요? (형식이 없으면 매번 달라져요)
- [ ] 계산이 필요하면, AI가 아니라 계산 도구가 하게 할 수 있나요? (예: 시트 수식 · 작은 스크립트)
